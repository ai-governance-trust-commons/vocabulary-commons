Machine access

Use the Library in software.

Discover, retrieve and cite attributed findings with their qualifications intact. The same provisional evidence is available to human readers, research tools and AI consumers.

Start with the catalog

catalog.json describes the current dataset and links to schemas, indexes, source records, downloads and guidance. For repeated analysis, download the complete public dataset once and work locally. Targeted consumers can retrieve individual bundles without downloading the whole collection.

Stable records with context

For example, EVID-159.json includes its full finding, limitations, original source, supporting location, case context, glossary relationships, verification status and publication attribution. A successful download does not mean the claim is independently verified.

Use the distinctions

Keep source findings separate from Commons interpretations. Preserve limitations, contrary evidence and source dependencies. A case is not necessarily an incident; multiple source records may share one underlying study. Publication, inspection and independent verification are different judgments.

Rights and scope

The founding glossary retains its recorded CC BY 4.0 license. This release does not assert a separate blanket reuse license for Library summaries or metadata, or grant rights to underlying publications. Read the rights statement before reuse. No source publication copies are distributed.

A versioned starting point

Machine release 0.5.5 uses contract 1.0 over dataset 0.5.6. File checksums help detect inconsistent or mixed downloads; they do not prove factual truth. This first phase does not claim a complete historical change feed. Return to the Evidence Library.
