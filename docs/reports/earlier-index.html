Historical preservation rules

  1. Keep the October 26 editorial reset: repository as durable case record; watch as selective interpretation; no low-signal daily inventory.
  2. Preserve a clear separation between real incidents, controlled studies, allegations, hypotheses and institutional responses.
  3. Preserve negative findings and deduplication. Do not treat the number of reports or cases as a success metric.
  4. Preserve unique mechanism observations even if the source incident is already represented in GitHub.
  5. Recover originals from their conversation or task run records before quoting any older report publicly; this index alone cannot support exact quotations.
