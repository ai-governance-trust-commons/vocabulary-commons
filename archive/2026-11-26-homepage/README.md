# Commons homepage before the November 26 redesign

This snapshot preserves the original homepage, stylesheet and navigation script byte for byte from [revision 7af4a41](https://github.com/ai-governance-trust-commons/vocabulary-commons/tree/7af4a415ff783c29c746e62d206e8dd5d30b6b63/docs). Open index.html to review the design. The original relative content links resolve when the files are placed at the corresponding paths under docs/ in a checkout of that revision.
